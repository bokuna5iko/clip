# Clip

Небольшой менеджер буфера обмена для Windows. Приложение работает в фоне в области уведомлений, запоминает скопированный текст, снимки и файлы и позволяет быстро вставить любой элемент обратно в буфер.

## Запуск

Из корня репозитория:

```bash
dotnet run
```

## Управление

- **Горячая клавиша буфера:** Ctrl+Shift+V — показать или скрыть панель
- **Горячая клавиша шкафа:** Ctrl+Shift+Space — показать шкаф поверх окон; повторное нажатие возвращает его на рабочий стол
- **Трей:** левый клик по иконке — панель; правый клик — «Открыть» и «Выход»

## Данные

История и снимки хранятся в `%LocalAppData%\Clip` (база `clip.db`, папка `images`).
