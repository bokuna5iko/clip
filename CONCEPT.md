## Уже собрано

Clip — фоновое приложение Windows в трее.

- Горячая клавиша `Ctrl+Shift+V` или левый клик по иконке открывает тёмную панель буфера.
- Панель помнит скопированный текст, снимки и пути к файлам.
- Клик по строке возвращает элемент в буфер. Вставка в другое окно — обычный `Ctrl+V`.
- Текст хранится целиком, не больше 1 МБ на запись.
- Снимок хранится копией PNG, не больше 20 МБ.
- Файл в историю не копируется, сохраняется только путь.
- Список обрезается до 300 записей.
- В настройках: запуск с Windows и срок хранения в днях. `0` значит не удалять по сроку.
- Данные: `%LocalAppData%\Clip` (`clip.db` и папка `images`).
- Сборка exe: `dotnet publish -c Release`. Файл: `dist\Clip.exe`. Запускать его двойным щелчком или ярлыком, не из терминала: закрытие терминала завершает процесс.

Буфер и шкаф — одна программа. Шкаф ещё не написан. Не ломай поведение буфера, пока пользователь явно не попросил. Клавиша буфера `Ctrl+Shift+V` остаётся у буфера. Клавиша шкафа — `Ctrl+Shift+Space`.

## Зачем шкаф

На рабочем столе пользователя несколько десятков текстовых заметок, плюс папки и программы. Часть уже разложена по папкам, остальное лежит россыпью, и глазами это тяжело разбирать.

Ему нужен шкаф, а не автоматическая уборка. Полки он собирает сам. Книги на полки ставит сам. Книга — заметка, папка или программа. Полка — группа с именем: прозрачный прямоугольник на обоях. Внутри книги лежат сеткой значков. Куда положил, там и лежит, пока сам не переставит.

По ощущению это обычная папка, только нарисованная на рабочем столе. Не система тегов, не правила, не категории меню «Пуск».

Ориентир по картинке: рабочий стол Windows 11, поверх обоев прозрачные прямоугольники. Внутри значки. Пустой прямоугольник тоже бывает: полка, которую он навёл, но ещё не наполнил.

Меню «Пуск» было только отправной точкой. Не копируй его и не читай его закрепления.

## Что уже решено

Шкаф — одно окно на рабочем столе. Высота окна всегда одна и та же. Ширину можно потянуть за край и отдельно раскрыть на весь монитор. Выбранные ширина и положение запоминаются. `Ctrl+Shift+Space` показывает это же окно поверх других программ в тех же размерах. Повторное нажатие возвращает его на рабочий стол, под другие окна. Окно при этом не закрывается и с рабочего стола не пропадает. Esc для этого не используется.

Окно делится на три полосы сверху вниз. У каждой свой зум, как масштаб значков в проводнике. Размер значков и то, сколько их влезает в полосу, задаёт зум и ширина окна. Числа и пиксели в концепции не фиксируются. Зум каждой полосы запоминается. Колёсико мыши с Ctrl над полосой меняет её зум.

1. **Закреп** — отдельные книги для постоянного быстрого доступа: файлы, папки, программы. Группы здесь создать нельзя. Книга попадает сюда перетаскиванием. Количество не ограничено. Лишние уходят в прокрутку полосы, а не обрезаются.
2. **Недавние** — любые недавние файлы Windows. Тоже прокручиваются, если не влезают.
3. **Группы** — нижняя область. На лице полки сразу видны первые четыре книги в порядке полки, как плитки в меню «Пуск». Этот предел четыре — единственное фиксированное число. Зум меняет размер этих четырёх значков, но не их количество. Четыре значка на лице — превью, по ним файл не открывается.

Над полосой «Закреп» стоит поле поиска. Оно ищет книги в группах и в «Закрепе», не по всему компьютеру и не по «Недавним», если такого файла нет среди наших книг.

Полки стоят внутри этого окна и передвигаются только внутри него. Размер полки пока не меняется. На скрине рамки разного размера, в первой версии все полки одного размера. Новая полка создаётся правым кликом по пустому месту окна. Окно перехватывает клики по своей площади, меню рабочего стола Windows там не открывается. У полки есть имя.

Книга попадает на полку перетаскиванием. Файл на диске не переезжает и не копируется: полка запоминает путь. Рабочий стол остаётся папкой, где файлы лежат как раньше. Чистота экрана делается тем, что значки Windows прячутся, пока шкаф работает. Тащить книги нужно из проводника, из папки «Рабочий стол» или из любого другого места. Когда программу закрывают, значки Windows снова показываются.

Один и тот же путь можно положить на разные полки, если тащить его из проводника на каждую. Перетаскивание книги с полки на полку забирает её с первой и кладёт на вторую. Файл при этом остаётся на месте.

Снять книгу с полки и удалить файл с диска — разные действия. Снятие убирает путь только с этой полки. Если файл удалили на диске, книга пропадает из всех полок.

Внутри полки значки сеткой, в том порядке, в каком их положили. Перетаскивание внутри полки меняет порядок, и на лице остаются первые четыре. Программа ничего не сортирует.

Поиск ищет только по книгам на полках, не по всему компьютеру. «Недавние» — любые недавние файлы Windows, даже если их нет ни на одной полке.

Чтобы открыть книгу в группе, сначала нажимают саму группу. Она раскрывается по числу книг внутри: чем больше книг, тем больше раскрытие. Соседние группы остаются рядом. Если места в полосе не хватает, полоса «Группы» прокручивается. Уже в раскрытой группе клик по книге её открывает, группа при этом не сворачивается. Сворачивается она кликом мимо неё: по пустому месту, по другой полосе или по другой группе. Клик по другой группе ещё и раскрывает ту. Книги в «Закрепе» и «Недавних» открываются кликом сразу, без этого шага.

Один монитор. Корзину Windows не трогаем. Родные значки Explorer по экрану из кода не двигаем.

## Чего не делать

- Не переносить и не копировать файл, когда его кладут на полку.
- Не подменять меню «Пуск» и не писать в его базу закреплённых значков.
- Не тащить `SysListView32` рабочего стола и не переставлять существующие значки Explorer.
- Не делать автогруппировку и не раскладывать полки самому.
- Не импортировать весь рабочий стол в полки сам.
- Не менять размер полки и высоту окна, пока это отдельно не попросили.
- Не искать файлы вне полок. «Недавние» к этому запрету не относятся: они берутся из недавних файлов Windows.
- Не использовать Esc, чтобы спрятать шкаф.
- Не удалять файлы из папки «Рабочий стол», когда прячутся значки.
